## Concept
- Specific ranges of IPs that are set aside for other use than to be used for traffic.

## Key Ideas
- This refers to the IP Addresses that cannot be used on  a network for traffic.
- Some notable examples are:
	  - [[IP Network portion|Network Address]] : a.k.a. Network Id, the first IP on a subnet, identifies the whole network.
	  - [[IP Broadcast portion|Broadcast Address]]: the last IP, sends traffic to every device on the subnet.
	  - [[Loopback Addresses|Loopback Address]]: used for testing/troubleshooting on the same machine.
	  - [[Private Address Ranges|Private Address Ranges]]: addresses reserved for internal networks that cannot be used on the internet
	  - [[APIPA]]: used when a device cannot contact a DHCP server
	  - Addresses save for future use/testing purposes.
