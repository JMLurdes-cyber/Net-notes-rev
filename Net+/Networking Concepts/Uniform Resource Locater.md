# Overview
- **URL** a.k.a. **Uniform Resource Locater** acts as an unique address used to access resources on the internet.

# Core Ideas
- Allows access into web pages, images, documents on the internet.
- Tells the browser the protocol to be used and the location to find it (the web address).
- Some of the protocols that can be used are:
	- [[NTP]]
	- [[HTTP - HTTPS]]
	- [[FTP]]
	- 
- Separated into three domains:
	- [[Top Level Domain (TLD)]]
	- [[Second Level Domain (SLD)]]
	- [[Third Level Domain (TRD)]]
	- [[Hostname]]
