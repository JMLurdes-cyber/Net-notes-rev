# Overview
Understanding how we use honeypots/honeynets to deceive potential intruders and study their movements in a secured environment.

# Core Ideas
| Honeypot                                                                | Honeynet                                                    |
| ----------------------------------------------------------------------- | ----------------------------------------------------------- |
| A system created to be vulnerable to attract and detect attackers       | Network of honeypots simulating a real network environment. |
| Helps in detection of unauthorized access, and to study their behaviour | Better analysis than the honeypot                           |
| Minimal functionality, it is meant to only be used during attacks       | Completely isolated from production network.                |
