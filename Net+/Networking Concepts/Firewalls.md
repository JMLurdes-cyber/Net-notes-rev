# Core Ideas
- Keeps tabs of outgoing connections, knowing when incomming connections are answers to previous queries or simply an unrelated one.
- Blocks any connection that is not expected/set up.
- Can be used to set up [[Demitilarized Zones]] using static [[NAT]] to give the DMZ an specific location.
- Based on rules.
- Separated between **Traditional** and **NGFW**.
- **Next Generation Firewalls** (NGFW) can even check the [[payload]] to check if it is harmful, alongside perform context based judgement (country of origin, common behaviour, etc).
