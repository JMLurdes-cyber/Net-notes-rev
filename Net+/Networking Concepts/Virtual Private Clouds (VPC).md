# Overview
 - **Virtual Private Clouds** or **VPCs** are private [[Virtual Networks|virtual networks]] within a cloud provider's virtual space.


# Core Ideas
- These allow for clients to have private spaces for their businesses within the public cloud.
- Usually consists of a full [[Virtual Networks]] created through the use of [[Network Function Virtualization]].
- Can be privately hosted or hosted by a provider such as:
	- **Amazon Web Services (AWS)**
	- **Google Cloud**
	- **Microsoft Azure**
	- **Oracle Cloud Infrastructure**
	- **Managed Service Provider (MSP)**; a locally chosen provider.
- Since the clouds can be hosted by a provider, they can also be located in several locations simultaneously, assuming that they have the resources to maintain them.
- There are several components used during the making of one:
	- [[VPN]]
	- [[VIRTUAL PRIVATE CLOUD GATEAWAY - INTERNET GATEAWAY]]
	- [[PRIVATE ENDPOINT]]

# Characteristics
- There are three main characteristics of a good cloud:
	- **Scalability**: or the ability to expand operations to accommodate new clients.
	- **Elasticity**: the ability to expand resources to accomodate more people within the current resources
	- **Multi tenancy**: the ability to locate the server in several places without disrupting operations.
