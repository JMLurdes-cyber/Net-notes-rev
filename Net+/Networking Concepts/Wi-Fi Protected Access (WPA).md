# ***Highly unsafe, do not use***

# Overview
Transitional protocol between [[Wired Equivalency Protocol (WEP)|WEP]] (unsafe) and [[Wi-Fi Protected Access Version 2 (WPA2)|WPA2]] (safe).

# Core Ideas
-  **Wi-FI Protected Access** a.k.a. **WPA** was the skeleton of the protocols that we use nowadays
- Used the same Cypher as [[Wired Equivalency Protocol (WEP)|WEP]], which was considered weak.
- Introduced the **Message Integrity Check (MIC)** to prevent attackers from altering data packets between clients and the [[Access Points|Access Point]].
- Introduced the [[Wireless Pre-Shared Key]] method.
