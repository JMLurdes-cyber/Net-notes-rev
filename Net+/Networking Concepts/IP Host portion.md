- The part of an [[IP Addresses|IP address]] that defines the specific device of a network.
- Within a single network, devices must have unique hosts to define them.
- Is like the name of a house in a street, the street being the [[IP Network portion|Network portion]]

# [[IPv4 Addressing|Host portions in IPv4 Addressing]]
- Can vary in size depending on the [[Subnet Masks|subnet mask]]

# [[IPv6 addressing| Host portions in IPv6 Addressing]]
- Will always be, in practice, 64 bits long.
- Their Host portions are called instead **Interface Identifier**
