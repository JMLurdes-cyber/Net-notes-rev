# Overview
Summarizing the uses of [[DNS]] in attacks and the preemptive measures

# Purpose
- Corruption of DNS cache with false records
- Facilitates Man-in-the-Middle attacks to intercept traffict.
- Can cause [[Denial of Service (Dos)|DoS]]
# Techniques
- Alteration of DNS server data

# Mitigation
- [[DNS Security Extensions (DNSSEC)]]
