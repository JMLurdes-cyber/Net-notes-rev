# Overview
The ability of a service/business to keep operation without (or  minimal) disruptions

# Core Ideas
- One of the principles of a good standing business.
- One of the key points of the [[Service Level Agreement (SLA)|SLA]], measured in percentage.
- Good availability depends on a [[redundancy]]-based system.


# Types
| Active-Active                    | Active-Passive                                                     |
| -------------------------------- | ------------------------------------------------------------------ |
| All systems share the workload   | One system is active, the other is in standby                      |
| Provides continuous availability | Simple to implement, but may involve downtime during [[Failover]]. |
| Complex and Expensive            |                                                                    |
