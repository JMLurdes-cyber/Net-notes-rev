# Core Ideas
- The top tends to be [[Single Mode Fiber]] set up for cabling that comes from elsewhere outside the building, like in [[WAN|WANs]].
- There are some that have [[Multimode Fiber]] that runs to the rest of the building for the rest of the floor ([[Copper Cablings|Copper cabling]] may also be used)
- The rest tends to be Network Hardware or media converters.
