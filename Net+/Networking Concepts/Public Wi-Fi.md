# Core Ideas
Connecting directly to the access points has several demerits:
		 Cannot access the connected devices easily
		 Cannot verify the identity of connected devices
		 Cannot ban the use of the services to specific devices hastily
	So instead we tend to use **Acces Portals** to do so.

- **Access Portals** are sites to which the end users connect to through (usually) the use of an username and a password. Since the user would be connected with easily verifiable credentials, those can be used at once in case of an incident to perform the aforementioned tasks.
