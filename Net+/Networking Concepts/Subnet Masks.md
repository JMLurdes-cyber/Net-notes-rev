## Concept
- It separates a network into neighborhoods, each one of them being isolated fom each other.
- It tells computer whether to send data locally or to go through a router to reach a parallel subnet.

## Key Ideas

 - Each device within a network will have a subnet mask.
 - Unlike the IP address, it isn't sent through the network.

# [[IPv4 Addressing|Subnet Masks in IPv4 Addresses]]
 - Like an [[IPv4 Addresses|IP address]], it is composed of 32 bits (4 bytes)
- Usually set up by the admin for ease of use.
- Different subnets within the same network can have different subnet masks using [[VLSM]]

# [[IPv6 addressing| Subnet Masks in IPv6 Addresses]]
- **They always have a /64 subnet mask**


# Examples
- 255.255.240.0
- 255.255.255.0
