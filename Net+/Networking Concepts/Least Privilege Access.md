- Security principle that denies entry to services that the user is not authorized to do
# Core Ideas
- The user can ONLY access the services that they are authorized to use.
- Aside from the bare minimum, everything else will be restricted.
- Both in case of an inside job or an outside job this prevents [[Threats (Security)|threats]] from coming into data that the user would never use 

# Examples
- In "Apotekstjanst" I cannot access the application's "security" tab since it contains information about the workforce and I do not have any reason to use that information without an authorized supervisor.
