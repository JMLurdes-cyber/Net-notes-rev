- [[UNDERSTANDING THE OSI MODEL|OSI Model]] Layer 7.
- This layer provides web services to applications. 
- Usually runs on [[Servers|servers]].
- Comptia states that it is responsible for protocol definition(like HTTP) , data formatting and emulation.
