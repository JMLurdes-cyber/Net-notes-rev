# Overview
Refers to all security techniques used to avoid data from being acquired from an external source after getting into the system.

# Core Ideas
- Refers to any kind of defensive practice that is put in place to avoid an attacker to access data that is not being sent through the network, like a database.

# Examples
- Full Disk Encryption
- File Level Encryption
- Database Encryption
