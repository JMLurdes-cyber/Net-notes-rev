# Overview
A summary and explanation of the most common cable used in [[LAN]] setups

# Core Ideas
- **8 cables twisted into 4 pairs**.
- Each pair is color-matched:
	- Orange - White
	- Green    -  White
	- Blue       - White
	- Brown   - White
- Each pair sends equal and opposite signals.
- Separated into **categories**, to showcase the minimum category needed to work properly following the [[IEEE| IEEE standard.]]

# Function
- By twisting, both cables are exposed to the same interference, which the receiving computer can subtract from the signal leaving only the data.
- The twist is differential to make each pair not interfere with each other.
- Usually uses a [[Copper Connectors|RJ-45]] for larger network connections

# [[Unshielded Twisted Pair (UTP)]]
- Most commonly used within networks

# [[Shielded Twisted Pair (STP)]]
- Mostly used in high speed communications/datacenters
- Usually signed by a "S/FTP" label on the cable's plastic
- CAT 8 cabling is ALWAYS shielded
- The cabling within the foil is shielded by aluminium.
- The [[Copper Connectors|RJ-45]] connector is usually set in a metal case, unlike the transparent plastic of an [[Unshielded Twisted Pair (UTP)]]
