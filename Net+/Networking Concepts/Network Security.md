# Network Segmentation
Refers to the practice of breaking a network into several sub-networks that are each able to perform different functions within the organization.
An example would be:
	 - Having a client-side network and a work-side network


# Information Security in Industrial Environments
Ensures the safety, reliability and continuity of physical processes, such as power plants, instead of focusing on the data confidentiality.
The three main kinds used are:
- [[Supervisory Control and Data Acquisition (SCADA)]], which collects real time data and logs events.
- [[Industrial Control Systems(ICS)]], umbrella term. SCADA is a part of ICS
- [[Operational Technology (OT)]], which detects or causes changes to physical devices

# Audits and Regulatory Compliance
Overview on the different rules and regulations set up for the handling of data over different networks, or within them.
- [[Data Locality]] Ensures that data is stored and processed geologically, complying with the laws and regulations of the region.
	- For example, an application not allowed in X countries not reaching the country's network.
- [[Payment Card Industry Data Security Standards (PCI DSS)]] refers to the set of standards set in place to mandate secure handling, storage and transmission  of credit card information, from personal information to bank information.
- [[General Data Protection Regulation (GDPR)]] refers to the standards set in place to govern over data protection and the privacy of individuals **within the EU**.
