# Overview
Understanding the different kind of attacks the [[ARP]] can receive within a network

# Core Ideas
- An attacker sends fake ARP messages to the the associate, masking their [[MAC Addresses|MAC]] with one from a trusted device.
- The result is the attacker's device **looking like part of the network**.

# Solution
- Detection capabilities on switches
- Deep ARP inspection
- **Legacy attack, mostly covered by newer switches**
