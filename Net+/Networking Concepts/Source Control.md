# Overview
- **Source Control** or **Versioning** refers to the following of the versions of an update for both logging and development purposes.

# Core Ideas
- Allows for the seamless upgrading/updating of [[Virtual Private Clouds (VPC)]], alongside testing and development.
- Through the use of **branching** we can create separated update "lines" to test individual parts of the process. These branches can be **merged** at a later time if needed.
# Examples
- **GIT** is one of the most well known versioning sites.
