# Overview
Understanding the basics of [[networking documentation]] through an explanation of diagrams used for both physical and logical connections.


| Physical Network Diagrams                                                          | Logical Network Diagram                                                                                |
| ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Includes mainly physical hardware and cabling                                      | Represents the data flow, network desings                                                              |
| Useful in deployment of new hardware + [[physical layer\|layer 1]] troubleshooting | Useful in network design, higher [[UNDERSTANDING THE OSI MODEL\|OSI]] troubleshooting and optimization |
| Detailed view of physical placements and connections                               | Components are [[IP Addresses]], [[VLAN\|VLANs]], routing protocols                                    |


### Physical examples:
#### Server Rack Diagrams
- Usually comes as a downloadable file with the server rack
- Some softwares allows to save data into the file
- Explains the functions/connections of the devices within the [[Hardware Installation|Server Rack]].

#### Cable Map Diagrams
- Mapping of the cabling connections within the rack/to the devices
- Meant to be accurate and updated to the last cable.

### Logical Examples:
#### Network with [[Demitilarized Zones|DMZ]] Segment Diagram
- Shows the ports being used by the devices within the DMZ
- Shows the [[IP Addresses]] of devices within the network
- Shows the segmentation between DMZ and the inner devices through the firewall

### Hybrid Examples
#### Wireless Survey/Heatmap Diagram
- Mapping of the connectivity of the [[WIRELESS NETWORKS|wi-fi]] within a building.
- Contains information of both the wifi itself and the positioning of the [[Access Points]].
