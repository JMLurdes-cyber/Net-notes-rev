# Overview
- GRE protocol, a.k.a. **Generic Routing Encapsulation** is a protocol that creates a link between two networks. That link allows for packets to be directly transmitted between them, ignoring packet restrictions or distance.

# Core Ideas
- Every packet being sent through it is **plaintext** (unless other protocols are added).
- It is a foundational protocol in [[VPN|VPNs]]
- Can send packets using [[IPSec]] to send [[multicast]] encrypted packets, unlike [[vpn|vpns]].
- Used along the [[Virtual Extensible Local Area Network (VXLAN)]] protocol to send packets between data centers mimicking a direct connection.
