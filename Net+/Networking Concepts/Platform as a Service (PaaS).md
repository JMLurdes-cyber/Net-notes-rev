# Overview
- **Platform as a Service (Paas)** refers to the cloud model in which the provider hires the hardware and the Operative systems.

# Core Ideas
- The client handles the:
	- Maintenance of the service

- The provider takes care of:
	- The operative system
	- Hardware
	- Maintenancef

# Examples
- Useful for the building, testing, deployment and development of web services.
