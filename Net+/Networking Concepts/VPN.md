# Overview
- **VIRTUAL PRIVATE NETWORKS** or VPNs create secure, encrypted connections over the internet, allowing secure remote access and making devices appear inside another network.

# Core Ideas
- Through the use of their [[Tunneling|tunneling]] protocols ([[AH]], [[Generic Routing Encapsulation (GRE)]], [[ESP]])they can allow a client to connect remotely with the server.
- They also hide the client's original IP.
- Best used in encrypted [[unicast]] communications, [[Generic Routing Encapsulation (GRE)]] is much better at [[multicast]] communications.

### Use with [[Virtual Private Clouds (VPC)|VPCs]]
- Clients can use them to remotely connect to the [[Virtual Private Clouds (VPC)|VPC]]
- Also useful on hybrid set-ups
- Can be used through an [[Agents|agent]] or without one
