# Core Ideas


# Types:
### Cold Site 
**Only the basic infrastructure is set up**
-Basic backup infrastructure set up
-Contains the power and equipment
+Not at operating capacity, everything needs to be fixed.
+Cheapest kind
### **Warm site**
**Some connections are prepared, but still needs to be fully set up**
-Partially equipped backup site
+-Balanced cost and recovery

### Hot Site
**Fully operational, can be used whenever through the used of replication**
+Fully operational
+Immediate recovery
-Most expensive to  set up
