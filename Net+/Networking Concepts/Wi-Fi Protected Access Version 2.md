# Overview
**Wi-Fi Protected Access Version 2** a.k.a. **WPA2** came as a newer, safer version of [[Wi-Fi Protected Access (WPA)|WPA]]

# Core Ideas
- Mandated the use of [[Advanced Encrytpion Standard (AES)|AES]], a much stronger encryption than RC4.
- Mandatory authentication
- Added WPA2-PSK, which allowed for the use of [[Wireless Pre-Shared Key]], stronger than the ones used by [[Wi-Fi Protected Access (WPA)|WPA]]
- Added WPA2-Enterprise, which allowed each user to have their own credentials instead of sharing one single password.
