## Concept
- A Virtual IP Address (a.k.a VIP) is an IP address shared or moved between multiple devices.

## Key Idea
- The VIP can be used by **only one device at a time**.
- It appears as a single host to the clients.
- If the device fails somehow, the VIP can be moved to another device that shares it providing redundancy and/or load balancing.
- Common in: 
	- [[Firewalls]]
	- [[Routers]]
	- [[Load Balancer|Load balancers]]
	- Clustered servers
- Useful for providing:
	- High availability
	- Load Balancing
	- Simpler client configuration
