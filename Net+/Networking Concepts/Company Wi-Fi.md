# Overview
Wi-fi exclusively set-up for the company use

# Core Ideas
- Usually meant to be safer/sturdier than [[Public Wi-Fi]].
- Has more trusted methods of authentication, such as:
	- Verified name + password
	- Only allowed access from devices **certified**, which are set-up by the admins.
	- Only the admins knowing the password
- The authentication is performed in the directory services system, which contains the logs of the allowed connections
