# Overview
Framework of technologies and techniques that verify the identity of an user attempting to access an endpoint.


# Core Ideas
Over time, we have developed several methods of authentication:
	- [[Single Sign On (SSO)]]: Ensures that a single user has an unique identifier. That identifier can be shared among multiple services, but **only one may be used per user**.
	- [[Multiple-Factor Identification (MFA)]]: Ensures that to access a service you are required to use multiple forms of authentication
