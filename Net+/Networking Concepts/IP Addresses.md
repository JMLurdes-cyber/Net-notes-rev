# Overview
Unique Identifiers that locate devices/services within a network.

# Core Ideas
- Separated into two kinds:
	- [[IPv4 Addresses]]: that use 4 bytes (4 sections of 8 bits each), making 32 bits total.
	- [[IPv6 addressing|IPv6 Addresses]]: that use 8 sections of 4 bits written in hexadecimal, making 128 bits total.



- Ip addresses are separated into two portions: **network** and **host**.
	- **[[IP Network portion]]** represents the group of devices that the IP uses
	- **[[IP Host portion]]** represents the specific group and device that the IP uses.
