# Overview
Understanding the basics of [[Comptia Network Implementation]] by explaining how VLANs are set on the network,  even connecting different devices to the same VLAN through the use of Trunk Links.


# Core Ideas
- Cable that connects two [[switches]] together whilst keeping the [[VLAN|VLANs]] separated.
- Uses the protocol **802.1Q** a.k.a. **VLAN Trunking**.
- It works by adding a VLAN tag to the [[Frame header]] after the Source [[MAC Addresses|MAC Address]], identifying to which VLAN the device is a part of.
