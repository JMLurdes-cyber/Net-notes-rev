# ***This protocol has been deprecated due to it being highly unsafe. Never set-up/trust any network using this protocol as basis.*** 


# Overview
**Wired Equivalency Protocol** a.k.a. **WEP** was one of the protocols that attempted to increase the security of wireless networks. 

# Core Ideas
- Used 64/128 bit protection + a [[Wireless Pre-Shared Key]] to protect data.
- Failed due to the supported keys being too short, which made them easily crack when attacked by more modern computers
