# Overview
- Protocol that allows remote Data centers to be connected together as a [[DATA LINK LAYER|layer 2]] connection (without using [[IP Addresses]]).

# Core Ideas
- Used in **top** of [[Generic Routing Encapsulation (GRE)]] to allow remote direct connections.
- Allows the transferal of [[VLAN|VLANs]] between [[Data Centers]].
- Two connected data centers will appear as a single conjoined location to the connected devices, facilitating management.
- Used commonly in [[Data Center Interconnect (DCI)]]
