# Overview
Reviewing each of the methods for the encryption of [[Wireless Networks]].

# Core Ideas
- Since [[Access Points]] are by nature unsafe, since the connection is send through waves everywhere, we require more methods to avoid [[Threats (Security)|threats]] into the network.
- Several Protocols have been developed throughout the years, and more will come in the future probably.


### [[Wired Equivalency Protocol (WEP)]]
- ***This protocol has been deprecated due to it being highly unsafe. Never set-up/trust any network using this protocol as basis.*** 

### [[Wi-Fi Protected Access (WPA)]]
- ***This protocol has been deprecated due to it being highly unsafe. Never set-up/trust any network using this protocol as basis.*** 
#### **[[Wi-Fi Protected Access Version 2]]**
- Most common protocol used nowadays.

#### **[[Wi-Fi Protected Access Version 3]]**
- Latest standard of wireless encryption used
