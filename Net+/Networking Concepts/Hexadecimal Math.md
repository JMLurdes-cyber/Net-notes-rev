- **Hexadecimal values (or Base 16 values) are a foundational part of [[IPv6 addressing]]**
- The math follows the whole sequence from 0-9 and then borrows the letters A, B, C, D, E and F to reach up to the destination value.
- Used in networking since a single hexadecimal value **easily represents [[Binary Math|4 binary bits]]**.
- Usually preceded by a **0x**, which showcases that  the following number follows the Base 16. That value is usually ignored during conversions.

For example, 1**3 in Base 10 would be 0xD in hexadecimal**.
