# Overview
Reviewing each of the safety measures used commonly in networks

# Core Ideas
- The most common method is a **[[Wireless Pre-Shared Key|Pre-Shared Key]]**; an alphanumeric value that we input to connect to the [[Access Points]]. This method is not the safest.
- Companies tend to separate the network into:
	- [[Public Wi-Fi]]: which commonly connects client devices to the wifi through an Access Portal.
	- [[Company Wi-Fi]]: which usually has more rigorous authentication.
