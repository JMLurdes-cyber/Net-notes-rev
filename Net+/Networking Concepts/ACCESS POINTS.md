# Overview
- Provides wireless access to a wired network, connecting [[WIRELESS NETWORKS|wi-fi]] devices to the [[LAN]].

# Core Ideas
- Multiple APs (Access Points) can be connected together to keep seamless roaming.
- If the building is a small one, a [[routers|router]] can be used as an access point.

# Functions
- Uses [[Band Steering]] to seamlessly allow devices to connect to the correct frequency.
- Most devices come with several antennas, one for each frequency.
