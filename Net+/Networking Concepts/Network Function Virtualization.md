# Overview
- **Network Function Virtualization** or **NFV** describes the replacement of network hardware with virtual versions that fulfill the same functions.


# Core Ideas
- The digital version of the components also takes up the functionality of the physical ones, virtualization the functions inside a network.
- This makes networks easier to deploy, scale and manage.
- An example would be changing a firewall hardware with a firewall software.
- Used in [[Virtual Networks|virtual networks]].
- The range is equal to the physical counterparts; it can refer to [[Routers|routers]], [[Load Balancer|load balancers]], [[Firewalls|firewalls]], servers, etc.

# Examples
- Running a virtual [[Switches|switch]] that forwards packets from a virtual [[Routers|router]] to a virtual host server in the same virtual [[Subnets|subnet]].
