
# Overview
- **INTRUSION PREVENTION SERVICES** or **IPS**s monitor, detect and prevent intrusion attempts made on the network in real time.

# Core Ideas
- It can also drop packets or connections if anything possibly harmful to the network is detected.
- Keeps a database with known [[Exploits|exploits]].
- Tends to be paired with an [[IDS]] and a [[Firewalls|firewall]].
