# Overview
- Methods that [[IPv4 Addressing|IPv4]] and [[IPv6 addressing|IPv6]]  use to interconnect with each other. IPv4 and IPv6 **cannot directly communicate with each other.**

# Core Ideas
- There are three main types of interconnection:
	- [[Dual Stack]]: which refers to a device running both IPv4 and IPv6 simultaneously.
	- [[IPv6 Tunneling]]: which refers to a IPv6 packet being wrapped inside an IPv4 packet to travel
	- [[IPv6 Translation]]: which revers to converting IPv6 packets to IPv4 and vice-versa.
