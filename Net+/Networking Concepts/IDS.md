# Overview
- **INTRUSION DETECTION SYSTEMS** or **IDS** monitors networks in real time.

# Core Ideas
- Responsible of monitoring, detecting and alerting any intrusion attempts made to the network.
- It also logs events that occurred.
- Has a database with known [[Exploits|exploits]].
- Tends to be paired with an [[IPS]] and a [[Firewalls|firewall]].
- Needs to be fine-tuned; known to have lots of [[false positives]].
