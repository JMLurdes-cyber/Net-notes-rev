# Overview
- Protocol that collects and manages log messages from all over the network into a single database.

# Core Ideas
- Collects all data from within the network into a single database
- Simplifies analysis and the monitoring of system events, incidents or application/user behavior.
- Requires a lot of space, since it consolidates all logs into one.
- Required protocol in most [[Security Information and Event Management|SIEMs]].
### Ports used
- [[UDP]] 514
