# Overview
Refers to the security techniques used to protect data in the path from A to B. Basically, it is fully about avoiding attackers to "tap the wire".


# Examples
- [[SSL - TLS]] with [[HTTP - HTTPS|HTTP]]: Uses a [[Digital Certificates|Digital certificate]]
- [[VPN|VPNs]]: Secure Tunnel over an unsecure medium, such as the Internet.
