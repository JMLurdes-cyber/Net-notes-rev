# Overview
- **[[Uniform Resource Locater|URL]]/Content Filters** a.k.a. **proxies** implement policies over the internet connections made within a network based on the users

# Core Ideas
- Sits between client and server catching the interactions and deciding whether the request can go forward or if it should be dropped.
- Can be used to set up rules, catch malicious data or to hide the client identity from servers.
- Can be used to block nsfw content in job networks, for example
