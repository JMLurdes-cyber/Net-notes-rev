# Overview
- Networking approach combines the configuration of the devices of a section into a single place, which can be configured by admins to affect all devices of the section simultaneously.
# Core Ideas
- Used during the deployment of [[Virtual Private Clouds (VPC)]]. 
- Can be deployed Locally.
- "Hides" the structure of the network, facilitating management for the people running the applications.
- Automatically provides everything needed for a web server to function properly through the use of a [[Central Policy Management]]
- Separates sections of the network by function, collapsing everything into an easier to manage server.
- Ignores the [[data link layer|layer 2 network]] and the [[network layer|layer 3 network]]: as long as they work they are "irrelevant"(even though they need to be set up for it to work).
- Can also be set up with a [[Wide Area Network (WAN)]] to make a [[SD-WAN]].
- Can be used with [[Zero-touch Provisioning]].
