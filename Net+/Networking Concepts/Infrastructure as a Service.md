# Overview
-  Cloud model in which the provider hires out hardware resources, and the client is the one responsible from everything of the network.

# Core Ideas
- **Infrastructure as a Service (SaaS)** is the cloud model in which the provider rents out the maintained "free slot", and the client is the one that uses it as they want.
- The client takes care of the:
	- Applications used
	- Virtual layout (virtual [[Network Architectures|architecture]], for example)
	- Runtime
	- Data

- The provider only hires out the processor power, memory power and operative system.

# Examples
- Useful to deploy a fully operative [[Virtual Networks|virtual network]].
