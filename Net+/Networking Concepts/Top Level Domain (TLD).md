# Overview
- **TLD** a.k.a. **Top Level Domain** is the final segment of a [[Uniform Resource Locater|domain]] name located after the *last dot*.

# Core Ideas
- Organizes websites by:
	- purpose
	- type
	- geography

- Usually separated into:
	- **Generic TLDs (gTLDs):** The most common TLDs, intended for general or commercial use (.com, .net, .info, .biz)
	- **Country-Code TLDs (ccTLDs):** Two-letter codes identifying a specific country or geographic region (.de, .uk, .ca, .es, .se)
	- **Sponsored TLDs (sTLDs):** Restricted, specialized TLDs managed by private organizations (.gov, .edu, .museum)
	- **Infrastructure TLD:** The .arpa domain, used exclusively for technical infrastructure like [[Reverse DNS Lookup|reverse DNS lookups]]
