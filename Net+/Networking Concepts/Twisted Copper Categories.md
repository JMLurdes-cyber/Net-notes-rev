- This is an explanation of each [[Ethernet]] category, following the [[IEEE|standard]].

| Category      | Use Case                     | Standard                |
| ------------- | ---------------------------- | ----------------------- |
| Cat 1         | Doorbell                     | Not used in "networks"  |
| Cat 3         | Telephone / 10 Mbps Ethernet | 10BaseT (Mostly unused) |
| Cat 5         | 100Mb Ethernet               | 100BaseT                |
| Cat 5e        | 1 Gb Ethernet                | 1000BaseT               |
| Cat 6         | 1 Gb Ethernet                | 1000BaseT               |
| Cat 6a/ Cat 7 | 10 Gb Ethernet               | 10GBaseT                |
| Cat 8         | 40 Gb Ethernet               | 40GBaseT                |
