- [[TRANSPORT LAYER|Layer 4]] protocol.
- Provides reliable, ordered and error-checked delivery.
- It is communication-oriented, it always receives an acknowledgment of start and end of communications based on a set of agreed parameters.
- This **[[TCP Three Way Handshake|three way handshake]]** is performed on every transmission, verifying which data reaches the destination and the state of said data.
- Adds a [[Transport Header]] to the packets.
	- This header will include:
		- Sequence Number
		- Acknowledgement Number
