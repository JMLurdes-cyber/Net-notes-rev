# Overview
Electronic documents that verify ownership of a public key, ensuring safe communications over the network.

# Core Ideas
- Must follow the **Public Key Infrastructure (PKI)**; which is a framework of policies and technologies that create, manage, distribute and revoke Digital Certificates.
- Can be: 
	- **Self Assigned**: Unsafe keys done by the internal users, used for testing
	- **PKI**: Private and/or public certificate Authority
