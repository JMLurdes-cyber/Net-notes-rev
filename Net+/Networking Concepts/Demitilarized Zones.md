# Overview
**Demilitarized Zones** or **DMZ** are isolated sections within a local network that allow incoming connections for client facing services.


# Core Ideas
- Isolated zone within a network that allows incoming connections.
- Not connected to the internal network (servers, devices, etc) to avoid [[lateral spread]] in case of an [[Exploits]]
- Usually set up using a [[Firewalls|firewall]] or a [[routers|router]]
