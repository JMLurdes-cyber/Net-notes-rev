- [[TRANSPORT LAYER|Layer 4]] protocol
- Provides fast communication, in which there is no need to verify the state of every bit of data.
- Connectionless, it simply sends the data without verifying if it was received or not.
- No flow control whatsoever.
- Since [[Firewalls]] are [[TCP]] based, UDP can be more useful whenever we want to sneak through Firewall, using protocols such as [[QUIC]]
