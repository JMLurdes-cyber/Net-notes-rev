# Overview
Information about the different terminologies used in networking to describe functionality


# Core Ideas

Separated into four main terminologies:

#### Flow Data:
- Summarized network traffic information
- Which devices communicate with each other
- Amount of data transferred

#### Packet capture:
- Recording of data packets as they traverse through the network.

#### Baseline metrics:
- The standard performance of a network under normal conditions.

#### Anomaly alerting/notification:
- Detecting deviations from the baseline metrics
