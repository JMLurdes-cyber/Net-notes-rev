## **Concept**
- A conceptual framework that divides the network communication into 7 layers to standardize how systems interact

## **The 7 layers**
- Layer 7: [[2026-03-03ApplicationLayer|Application]] 
	- Provides client input to web applications
- Layer 6: [[2026-03-03PresentationLayer|Presentation]]
	- Translates between client and machine
- Layer 5: [[2026-03-03SessionLayer|Session]]
	- Manages the connection between client and end service
- Layer 4: [[2026-03-03TransportLayer|Transport]]
	- Ensures reliable or fast transfer of data
- Layer 3: [[2023-03-03NetworkLayer|Network]]
	- Manages the routing between two networks
- Layer 2: [[2023-03-03DataLinkLayer|Data Link]]
	- Ensures node-to-node within a LAN
- Layer 1: [[2026-03-03PhysicalLayer|Physical]]
	- Encompasses the physical media and transfer.

## Uses
- Gives a standard during networking communications
- Allows for easier troubleshooting through the isolation of issues
