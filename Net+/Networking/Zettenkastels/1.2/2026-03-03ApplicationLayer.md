## **Concept**
- The layer that appears on the screen of a software, into which the user inputs their requests, alongside the layer that provides web services to applications over the internet.
## Key ideas
- It enables communications between the end user and the network.

## Functions
- Inputs client requests unto the network.
- Provides web services to applications.
- Formats data for transmission
- Identifies communication partners
