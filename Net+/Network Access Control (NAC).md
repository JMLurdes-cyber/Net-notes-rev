# Overview
Software or hardware appliances used in network environments to increase the security


# Core Ideas
- [[Authentication]] and [[Authorization]]: Verify device and user identity before granting network access.
- Compliance Enforcement: Devices must meet security requirements before connecting.
- [[Role-Based Access Control (RBAC)]]: Assign network access levels based on your roles, ensuring [[Least Privilege Access]].
